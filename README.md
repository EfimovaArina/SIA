# SIA — Smart Intelligent Assistant

**SIA** — интеллектуальный голосовой ассистент для управления компьютером под управлением Windows.

Проект предназначен для того, чтобы пользователь мог формулировать задачи обычным языком, а ассистент преобразовывал запрос в последовательность действий на компьютере.

> **Статус проекта:** программный продукт разработан и функционально готов. Публичная публикация приложения для массового скачивания на момент подготовки этого репозитория ещё не выполнена.

## Возможности

В коммерческой версии SIA планируется поддержать:

- голосовое управление компьютером Windows;
- запуск программ;
- взаимодействие с браузером;
- выполнение задач в Microsoft Word;
- поиск товаров в интернете;
- управление воспроизведением музыки.

## Как работает SIA

В общем виде обработка запроса состоит из нескольких этапов:

1. Пользователь активирует ассистента и произносит команду.
2. Речь распознаётся и преобразуется в текст.
3. Интеллектуальная модель анализирует запрос и формирует план действий.
4. Ассистент выполняет необходимые действия с помощью инструментов управления компьютером.
5. При необходимости используется анализ изображения экрана для поиска элементов интерфейса.

## Технологии

В проекте используются следующие технологии и инструменты:

- **Python** — основная логика приложения;
- **Faster-Whisper** — распознавание речи;
- **OpenWakeWord** — обнаружение ключевого слова активации;
- **OpenRouter** — обращение к языковым моделям;
- **Flet** — графический интерфейс;
- **PyAutoGUI / keyboard** — управление мышью и клавиатурой;
- **PyAudio** — работа с аудиопотоком;
- **MSS, OpenCV, NumPy** — захват экрана и обработка изображений.

Состав используемых моделей и библиотек может изменяться в ходе развития проекта.

## Для кого предназначен проект

SIA ориентирован на несколько групп пользователей:

- людей с ограниченными возможностями, которым голосовое управление может облегчить взаимодействие с компьютером;
- обычных пользователей ПК;
- студентов;
- офисных сотрудников;
- организации, заинтересованные в автоматизации отдельных компьютерных задач.

Для людей с ограниченными возможностями предусмотрена модель бесплатного доступа. Для остальных частных пользователей планируется 14-дневный пробный период, после которого стоимость подписки составит **299 рублей в месяц**. Для организаций предусматривается отдельная модель корпоративного лицензирования.
