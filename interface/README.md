## 🖥️ Пользовательский интерфейс

Главное окно приложения **SIA (Smart Intelligent Assistant)** разработано с использованием библиотеки [Flet](https://flet.dev/). Интерфейс имеет фиксированный размер **800 × 600 пикселей** и объединяет основные элементы управления приложением.

### Основные элементы интерфейса

Главное окно включает:
- кнопку запуска и остановки голосового ассистента;
- меню навигации по разделам приложения;
- профиль пользователя;
- раздел с инструкцией по использованию программы.

### Темы оформления

В приложении реализовано два варианта оформления:
- **Светлая тема**;
- **Тёмная тема**.

Пользователь может переключаться между ними в зависимости от своих предпочтений.

### Управление голосовым модулем

Для наглядного отображения состояния ассистента реализована визуальная индикация микрофона. При запуске и остановке голосового модуля изменяются:
- изображение кнопки;
- цветовое оформление;
- всплывающая подсказка.

Запуск голосового модуля осуществляется непосредственно из главного окна приложения. Для выполнения голосовых операций используется отдельный процесс, благодаря чему пользовательский интерфейс и механизм обработки голосовых команд работают независимо друг от друга.

### Архитектура

Реализованная структура обеспечивает взаимодействие пользователя с основными функциями SIA, разделяет интерфейсную и голосовую составляющие приложения и создаёт основу для дальнейшего расширения функциональности.
